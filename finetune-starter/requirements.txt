# Minimum versions are conservative floors, not guarantees. The transformers floor
# comes from its documentation (the 4.51 docs already use eval_strategy and
# processing_class). This starter was actually run (tiny-model smoke tests, small-model
# runs and one default-model run, all on CPU) with: torch 2.14.0 (CPU build),
# transformers 5.17.0, peft 0.21.0, datasets 5.0.1, accelerate 1.15.0 on Python 3.12.
# Older releases are untested. train_lora.py adapts to the evaluation_strategy ->
# eval_strategy and tokenizer -> processing_class renames by inspecting the installed
# signatures, but that fallback was only unit-tested, not run against an old release.
#
# GPU users: install the CUDA build of torch from https://pytorch.org/get-started/locally/
# first. CPU-only users can run:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
